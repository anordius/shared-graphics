# Shared Graphics

A centralized repository for hosting and sharing images (graphics) that can be reused across multiple documents, repositories, and platforms via direct URLs.

## Purpose

This repository is intended to:

- Store commonly used images (figures, diagrams, maps, charts, icons, etc.)
- Provide **stable, public URLs** for use in:
  - Markdown documents
  - GitHub READMEs
  - Reports and documentation
  - Websites
  - Presentations
- Avoid duplication of the same graphics across multiple repositories or documents

## How It Works

All images stored in this repository can be accessed via raw GitHub URLs and embedded elsewhere.
